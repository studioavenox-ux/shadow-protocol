# Models - Placeholder for Phase 2

Current prototype uses procedural BoxMesh and CapsuleMesh placeholders for performance.

Future models to add:
- Alex Mercer character model (humanoid, ~5k tris)
- Marcus Reed NPC model
- Vehicle models (sedan, SUV, police car)
- Building modular kit (facades, windows, doors)
- Street props (bench, trash bin, hydrant)

All models should be:
- Optimized for mobile (low poly, efficient UVs)
- Use shared materials where possible
- LOD support for buildings
- Embedded in .glb format for Godot
